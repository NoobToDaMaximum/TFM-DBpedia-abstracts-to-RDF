# Triple Counting Scripts

This folder contains tools to count simplified sentences, text-level triples, and RDF triples generated by the Text2RDF pipeline.

## 📘 `count_triples.ipynb`

This Jupyter notebook processes a CSV output from the extraction pipeline and reports:

- Number of simplified sentences.
- Number of text-level triples (`relations` column).
- Number of RDF triples (`rdf_triples` column).
- Average triples per abstract.

### ✅ Usage

1. Open the notebook.
2. Set the `CSV_PATH` variable at the top to point to your output CSV.
3. Run all cells.

The notebook will print total counts and per-abstract averages.

### 🔧 Requirements

- Python 3
- pandas
- Jupyter
